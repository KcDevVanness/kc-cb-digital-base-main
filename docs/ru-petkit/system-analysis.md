## 2 Продажи 销售三页

### 2.1 `/ads/products` — Продажи по сайту (источник — Я.Кит / Метрика)
- 功能: 站内 SKU 周/日/月销售矩阵.
- 筛选维度: 周期 (日历 + Текущий месяц/30 дней/3/6/12 месяцев)、каталог (`⚙ Товары`, Скрытые 5)、детализация (По дням/неделям/месяцам)、артикул·показатель.
- 指标: Продаж шт/₽、Расходы площадки (эквайринг/логистика/реклама живыми/ДРР живыми)、Маржа по продажам、Маржа по заказам、Ср. чек、Корзин、Переходы、Остаток/дней до OOS.
- 展示: KPI 头 + SKU×周期矩阵 (可展开费用); `↓ Экспорт CSV` 客户端生成 `Prodazhi_po_saytu.csv`.

### 2.2 `/ads/marketplaces` — Продажи по маркетплейсам (Озон · Маркет · Сайт)
- 功能: Ozon (реализация) + Маркет (заказы) + Сайт (Кит оплата) 三源对照.
- 筛选维度: 来源 (Озон/Маркет/Сайт/Тотал)、周期、каталог (Скрытые 7)、расходы (Кратко/Подробно)、детализация.
- 指标: Заказы шт/₽、Продажи шт/₽、Маржа по заказам % (прогноз)、Маржа по продажам %、ДРР ₽/% (факт + нач.)、Цена к получению/на витрине/Соинвест %、Остаток/дней、Показы/Переходы/Корзины/Заметки.
- 展示: KPI 头 + SKU×周矩阵 + 来源切换.

### 2.3 `/ads/summary` — Суммарный (Показатели + ОПИУ)
- 功能: 跨渠道月度汇总 + 月度 ОПИУ (损益) 双视图.
- 筛选维度: 头图周期 (30 дней)、来源四切、вид (Показатели/ОПИУ)、таблица周期 (7 месяцев, ЗАКРЫТ/ИДЁТ).
- 指标: Показатели (Заказы/Продажи/Средний чек/Себестоимость/Удержания/Возвраты/ДРР факт+начислено/Маржа/Маржа по заказам/Показы/Переходы/Корзины); ОПИУ (Продажи/Соинвест площадки/Расходы площадки/Реклама/в т.ч. бонусами/Себестоимость/Маржинальная прибыль/ROI/Косвенные и налоги全空).
- 展示: 渠道 30 天曲线 + 月×指标大表.

## 3 Реклама 广告四页 (+总览头部)

### `/ads` 头部 (Окупаемость)
- ДРР 头 (расход ÷ чистая выручка) + живыми口径 + 目标 ≤ 20% 偏离尺 + 按日动态 + 类型/类目结构 + ТОП товаров (ДРР по товару не считаем, 注 Директ расход不分 SKU).

### `/ads/types` — Я.Директ (источник — Я.Директ / Метрика)
- 功能: 广告类型周矩阵. 筛选: 周期、детализация.
- 指标: Расход/Покупки ₽/шт/ДРР/CPO/Корзины/Показы/CTR/Клики/CPC (+Медийная CPM).
- 类型: РСЯ / РЕТАРГЕТ / ПОИСК / Смарт-баннеры / Бренд (sd_brand) / МЕДИЙНАЯ.

### `/ads/brand` — Бренд-спрос
- 功能: 品牌认知 vs 类目 organica 对照 + 30 个月曲线. ВЫВОД: 品牌 top-1 但类目在 2–3 页, 月 упущено до 39 859 ₽.
- 指标: брендовый спрос/клики/ доля / позиции / CTR×позиция деньги / интент分组 / Метрика прямые+бренд+CR (×3,1 vs 非品牌).
- 方法见证据包 (Wordstat/Вебмастер/Метрика/Директ + 更新每 2 小时).

### `/ads/funnel` — Воронка
- 功能: 访问→购买漏斗 + 触点路径 + 渠道对照.
- 筛选: 归因 (Первый/Последний/Посл. значимый)、按周/月、1/3/6 мес/год.
- 指标: Визиты/Покупки (Метрика цель)/CR рекламы/CPA (last click)/Показы/CTR/各阶段转化/касания深度/渠道 Визиты·Покупки·Конверсия·Индекс.
- Источник правды: 购买 = Кит опла单经 purchaseID ↔ order_number 绑定; CPA = Директ расход join Метрика 转化.

## 4 Цены и расходы 价格与成本

### `/ads/reprice` — Репрайсер (44 SKU, цены от 28.09 00:05)
- 功能: 四平台价格 vs 成本 vs маржа对照, 带外链到平台卡片.
- 筛选: каталог (Скрытые 7)、площадка (Все/КИТ/OZON/МАРКЕТ/WB)、SKU.
- 指标: Себестоимость + 按平台 Цена покупателю/Соинвест %/Цена к получению/ДРР %/Расходы %/Маржа %; ср. маржа 31,6%, ср. соинвест Озон 47,8%/Маркет 44,9%/ВБ 29,9%; `~` = 近似 маржа; 亏损行标红 (如 PKL_3 Озон −223,5%).
- 站内改价走 `fetch /ads/reprice/kit_price` (只读未调用).

### `/ads/costs` — Себестоимость (手工)
- 功能: SKU 成本 + 站内费率手工维护, 下游一切站内计算的源头.
- 要点: Эквайринг факт 4,41% / Логистика факт 2,42%; 无事实用 запасные ставки; 自 28.09.2026 репрайсер/продажи/закупка/МП按 60 天事实.
- 表: №/Артикул/Наименование/Себестоимость ₽/Кит % (~60+ 行, артикул带 склад/фабрика后缀变体); `Сохранить` (只读未点).

## 5 Поставки 供应独立章 (`/supply`, 59 SKU)

- 定位: 采购/物流/库存子系统, 四 tab: Дашборд / План закупки / Поставки / Параметры.
- Дашборд: склад 32,0 млн ₽ / цикл 57 дн; 未识别在途 2 200 шт × 8 артикул (无采购卡/去 flag/工厂未知码, 不扣减需求); СРОЧНО 9 SKU (критично 8) 2,6 млн ₽; ПОТЕРИ 4,0 млн ₽; ИЗЛИШКИ 2,5 млн ₽ (+在途超 3,8 млн ₽); 首批表 + 积压表 (8% 仓库) + 在途 6 单 565 130 $.
- План закупки: 周期 57 = 30+25+2;  horizon 97 = 57+30+10; ПО РАСЧЁТУ 2 300 шт 3 358 091 ₽ 17 SKU; РИСК 4,0 млн ₽; ОСТАТОК 19 846 (自有 13 529 + ФБО 6 318); 状态 Все 59/Просрочено 9/Дефицит 9/Скоро 7/ОК 11/Излишек 10/Нет продаж 13; 列 ТОВАР/ЗАПАС/СПРОС/ЗАКАЗ ФАБРИКЕ.
- Поставки: 9 条登记 (3 生产 13 482 шт 390 352 $ / 3 在途 4 911 шт 174 778 $ / 3 已到 15 906 шт 646 806 $); 命名 = инвойс号否则 KC-номер; XLS 规格书按 `Model` 解析; 无装箱单 1 条 (PK26H09P329SJ).
- Параметры: 周期/窗口/保险/最小批量/需求权重 (50/30/20/0%) + 示例 (PKL_4SET 26,96 шт/дн → 1 079 шт; Потребность = 57+30+10 −  остаток − в пути); 规则 (去缺货日/ETA/季节性/积压阈/新 SKU); 季节性全 1,0 = 实际关闭; 成本取自 Себестоимость 页.

## 6 Выгрузка (`/export`, 会计用行明细)

- 功能: Я.Кит 行明细导出给会计. 警告 5 无成本 SKU: `PJ_EP1 / PPM_1 / PRCL10 / PRCL10_1 / pj_4uvc` (成本列空黄色, 进 `Без себестоимости` 表, 去 Себестоимость 页补).
- 筛选: `from/to` (按建单日; 付款日 Кит 不给) / `sku` 部分匹配 / `delivery` (COURIER/PICKUP_POINT/POSTAL_SERVICE/SELF_PICK_UP) / `status` ×15 / `fmt` (xlsx/csv — 参数名 `fmt`, `format=` 返回 400).
- 语义: 一行 = 一订单行 (单号按行重复); 整单三列 (доставка/товары/заказ сумма) 整单重复 — 禁止按列求和; 成本按 артикул 取自 Себестоимость 页 (ед. 单件 / сумма 小计).
- 实测: `GET /ads/export/download?from&to&sku&delivery&status×15&fmt=csv` → 200 `text/csv`, 文件名 `orders_<from>_<to>.csv`; 样本 (`sku=pk44`, 单日 5 行) 17 列: `№;Статус;Статус оплаты;Способ доставки;Стоимость доставки;Общая стоимость товаров;Общая сумма заказа;Артикул;Наименование;Кол-во;Цена;Сумма;Сумма с учётом скидок;Цена с учётом скидок;Себестоимость ед.;Себестоимость сумма;Дата создания`.

## 7 决策×频率×粒度 (回应俄方问题 1, 日/周/月三档全支持)

## 8 对接价值分级 (S/A/B/C, 只排 RU 已有页面)

- 定义: S = 断流即停摆; A = 直接省钱/算钱; B = 提效; C = 存档备查.
- 排序: `supply ≧ costs/reprice > marketplaces/summary/export > products > types > funnel > brand`.
- S — `/supply` (59 SKU, 缺口→自动生成 PO 草稿; 在途 ETA→收货计划; 超储→刹车).
- A — `/costs` + `/reprice` (себестоимость→`products` purchase 档/`trade_docs` 双口径; маржа→定价); `/marketplaces` + `/summary` (结算→`platform_ops` 对账差异队列; ОПИУ→`export_finance` + `trade_docs` 发票).
- B — `/export` (行明细→`platform_ops` 订单镜像); `/products` (站内销售→需求权重); `/types` (类型 ДРР→广告调参依据, 只存档).
- C — `/funnel` (漏斗存档)、`/brand` (品牌需求存档).
