# 财务模块完善 · 数据打通 · 老板驾驶舱

> 执行口径与需求明细在 [`.ai/specs/2026-09-28-finance-ledger-and-cockpit-data.md`](../../.ai/specs/2026-09-28-finance-ledger-and-cockpit-data.md)；
> 本文是给人看的需求，阶段计划见 [`../plans/finance-and-cockpit.md`](../plans/finance-and-cockpit.md)。
> 俄罗斯外部系统契约见 [`../ru-petkit/supply-sync-tech.md`](../ru-petkit/supply-sync-tech.md)。

## 背景与问题

现系统三条链（采购 `purchasing` / 外贸 `cross_border` + `trade_docs` / 收汇退税 `export_finance`）只到"单据"为止，钱只算到采购单：付款状态是派生值（`purchasing/lib/orderTotals.ts:93`）且没有统一出口；柜级运费/报关/保险/关税没有金额化落点；收货只动数量（`cross_border/commands/shipments.ts:703-726`），库存没有成本层，资金占用算不出来；收汇只有状态没有金额（`export_finance/data/entities.ts:44-45`）；没有损益；俄罗斯 PETKIT 的 16 个数据端点完全没有接。结果是老板六类数据（赚多少 / 货转不转 / 卖得好不好 / 花钱值不值 / 钱回不回来 / SKU 对齐）没有单一可验收定义，俄方页数字与中方账本各说各话。

为什么现在做：业务已把采购、发运、收货、收汇跑通并在系统内留痕（见 [`./cross-border-erp.md`](./cross-border-erp.md)），缺的是把它们变成钱的口径；且俄方接口契约已冻结（`docs/ru-petkit/supply-sync-tech.md`），第一阶段 8 端点可先联调。

## 目标 / 非目标

**目标**（可验证）

- 柜级费用可记、到岸成本可算：折 CNY 后**分摊总和 == 费用总和**（金额 2 位小数）；采购价与到岸价**两个口径并列**（每行带来源标签）。
- 应付/应收/库存资金占用/损益四类台账可查，且每个数字可指到源；跨币种分组展示不顺加。
- 俄方 supply 8 端点（§1–§7 + §1.1）可拉、可重放、断点可续；SKU 映射覆盖率可见；未映射 SKU 不静默合并。
- 老板驾驶舱一页看六类数，每数带 `as_of` 与来源；数据陈旧（> 24h）整页标出。
- 端到端链路（供应商 → 采购单 → 发运 → 收货 → 付款 → 收汇 → 退税）脚本化验收。

**非目标**

- 不做凭证 / 科目 / 总账 / 账期 / 账龄（用户决议：业务台账 + 派生损益即可）。
- 不写俄方数据（成本毛利回写等 `A.4` 敏感项勾选后才谈）。
- 不做俄文全文翻译、不重建俄方已有 BI 能力（广告归因、漏斗、品牌分析只存档引用）。
- 驾驶舱只读：唯一写口是"缺口 → 采购单**草稿**"，不自动下单。
- 不引入图表库（先用一方 SVG 组件）。

## 用户与场景

| 用户 | 场景 | 结果 |
|---|---|---|
| 财务 | 收到货代/报关行账单，记一笔柜费用 | 到岸成本页立刻看到每行/每 SKU 的成本与单价 |
| 财务 | 月度关账，对俄方 ОПИУ | 损益页行项与俄方页同名同序，差异 ≤ 0.2 п.п. / 20 ₽ |
| 财务 | 看应收未收 | 三类来源（收汇/平台结算/内部销售）一张表，未收只看是否真正收到 |
| 采购/业务 | 问"这批货到岸多少钱" | 到岸成本页双口径 + 缺成本清单 |
| 供应计划 | 按缺口补货 | 勾选行 → 生成采购单草稿；未映射 SKU 被拦下 |
| 老板 | 每天早会看四数 | 缺口 / 在途 / 积压 / ДРР 一页，可下钻到 SKU |
| 老板 | 数据陈旧 | 整页 banner 说明，不假装新鲜 |

## 验收标准

对应 spec 的 AC-001…AC-018，人读版：

1. 一笔 USD 1000 的柜费用 + 汇率 → 到岸成本 Σ分摊 == 1000 × 汇率（2 位），逐行单价（4 位）=（采购价 + 分摊）/ 数量。
2. 权重全 0 时退化到另一维度；都 0 时不出分摊（不是出 0）；缺汇率的费用行标红并被剔除，**绝不按 1 摊**。
3. 库存资金占用三源解析（最近到岸 → 采购价档 → 缺），缺的计 0 但单列"未计价数量"。
4. 应付台账四值与采购单详情手算逐单一致；应收三类各一行；收汇金额旧记录为空照常可读。
5. 损益行项与俄方 `/ads/summary` 对齐（误差 ≤ 0.2 п.п. / 20 ₽）；事实/预测不混列；口径未定的行不建、不计入合计。
6. mock 8 端点全量拉取行数一致、同 `as_of` 重放 0 新增、中途失败游标不推进。
7. 驾驶舱每个 KPI 与其来源接口逐一核对一致；无权限 403；游标断 > 24h 显示 stale banner。
8. 全链脚本通过：采购行已收数量 == 仓库余额；Σ到岸分摊 == Σ柜费用。
